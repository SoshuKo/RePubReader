# 新ダイヤの表示条件

出典: カラベイ_鉄道ダイヤ.txt。指定のGoogle Driveファイル（1FtvTMa5L7uwWdydGEasZgHd2nAz3lfIJ）、2026-10-12取得。原文を同じフォルダに保存。

- 路線別の始発・最終出発を適用。時間帯境界は06:00/09:00/17:00/20:00。翌日到着列車を途中で打ち切らず、前日の列車も表示。
- ツァパ線は偶数時00分/12分発、キラゴー停車10分/9分、所要75分/76分を明示時刻通りに再現。
- 短絡線ドゥラム136分、KIRT普通155分、夜間貨物00:30/01:30発・190分。KMRT普通235分、急行201分。セラン線209分。
- 空港急行は全主要駅の着発を明示時刻通りに設定。ビライツァ6分/8分停車、KMRT接続急行32分発/15分着を表示。編成の物理的連結・分割や車両折返しのシミュレーションは行わない。
- 国際特急は固定発車時刻、所要時間、セラン中央3分停車を適用。
- BRT全区間169分、工業区間22分。地下鉄1号線47分/2号線27分と時間帯別の間隔を適用。
- 資料が標準スロットと異なる始発・最終発車を指定する場合、その境界便を追加し、間の便はスロットに合わせる。空港急行04:45/21:00、KMRT普通05:00/20:00もこの方針。
- 資料に逆方向のスロットや中間時刻がない系統は同じ起点スロット・距離による推定時分を使う。ハヴァレイキ線都市圏は共通の時分で優等列車の追越しを抑制。山岳区間は旧速度水準を上限とする。
- 湾岸急行の「イラー中央毎時35分」は起点発車スロットとして近似。実際のイラー基準の運行整理、待避線、閉塞、全系統の最小間隔の監査は行わない。
- BRT工業区間毎時20分と全区間便キラティ27分発は資料内で最小10分間隔と両立しないため、明示されたスロットを優先し、運行成立を保証しない。
- KMRT急行の始発終電については定時接続を優先して05:32〜19:32/05:54〜19:54。日中は普通と急行を交互、朝夕は各1本/時。
- ハヴァレイキ線の区間特急・急行の営業時間、国境区間のダーフレイ止普通の追加設定など、詳細のない便は近似。総括の区間本数と各系統の記述に差がある場合は各系統の記述を優先する。
- ダーフレイは既存画像に座標がないため隣接駅間の概略位置に追加。地下鉄は地理的位置資料がないため、画像下部に模式図として表示。地下鉄3号線は新資料の対象外。

実測の列車位置ではなく、ブラウザの現地時刻から計算するダイヤシミュレーション。明示時分のない列車情報に「時分推定」と表示する。
